# Event-Driven Orchestration (Commit 42)

The event-driven orchestrator converts new information into deterministic work plans instead of invoking every model on every clock tick. It supports relevant news, new filings, unusually large price moves, portfolio changes, insight expiry, and scheduled reviews. Subscriptions route research signals to research review while portfolio and expiry signals can use a lighter portfolio-monitor path. Several events for the same agent and company at one simulation time are coalesced into a single planned run with all trigger types and source references preserved. Future-dated events are ignored until their knowledge time, maintaining the system's no-lookahead guarantee. Plans are normalized and deterministically ordered so the same historical inputs produce the same invocation schedule. The backtest now adds filing and insight-expiry timestamps to its event clock and can add an optional `scheduled_review_days` cadence without forcing scheduled inference by default. Applied fills emit portfolio-change triggers, while approved relevant news and statistically unusual tape moves emit research triggers. This design reduces unnecessary inference cost while retaining an inspectable record of why every review cycle was scheduled.
