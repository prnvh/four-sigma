# Batch experiments and ablations

`BatchExperimentRunner` executes a named matrix of backtests and compares every successful variation with one required baseline. `ExperimentVariant` freezes the selected agent versions, strategy and governance settings, and the model and prompt labels used by the caller's agent bindings. Its `without_agent()` helper creates explicit news-, company-, or risk-agent ablations, while `with_strategy()` creates threshold and portfolio-policy variations without mutating the baseline. The executor callback is responsible for constructing fresh stores, tapes, model clients, registries, and analyst bindings for each variant, preventing state leakage between experiments. Each result retains the complete `BacktestResult`, wall-clock execution duration, and deltas for every standardized strategy metric. A failed non-baseline variation is recorded with its error type and message so the remaining matrix can finish, while a failed baseline stops comparison because deltas would be meaningless. Model and prompt labels are experiment identity metadata that the callback can use to select the corresponding clients and versioned registries. This structure supports reproducible baseline, agent ablation, governance-threshold, model, and prompt experiments without putting experimentation logic inside the trading engine.
