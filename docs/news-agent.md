# News Agent (Commit 18)

The News Agent converts immutable news evidence into narrow, machine-readable observations for downstream research. It reads only news records exposed by the permissioned context gateway and cannot see information whose knowledge time is later than the requested simulation time, preventing future leakage in historical runs. Before any model call, it removes repeated articles using normalized URLs and headlines so syndicated copies do not amplify an event. The model may associate an event only with symbols in the supplied research universe and, when source entity tags exist, cannot contradict those tags. Each accepted result contains exactly an event ID, one or more entities, a controlled event category, and a relevance score from zero to one. Unknown event references, invented entities, duplicate outputs, invalid scores, and additional fields all fail validation. In particular, direction, sentiment, forecasts, trade recommendations, and other investment conclusions are deliberately outside this agent's contract. This makes the component useful for processing large news collections while keeping classification auditable, replayable, and safely separated from the News Analyst that forms investment findings.
