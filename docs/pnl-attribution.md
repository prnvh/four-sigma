# PnL Attribution (Commit 40)

The PnL attributor converts completed fill lineage into reconciled performance evidence for the research system. It reports realized PnL by agent, agent version, insight, insight category, news source, company, sector, confidence bucket, and holding horizon. When several sources or insights contribute to one fill, credit is split equally among the distinct contributors within that dimension so the dimension still sums exactly to portfolio PnL. Profits and losses retain their signs, preventing losing contributors from being hidden by absolute-value reporting. Every fill must have the complete event-to-fill lineage created in Commit 39 and must supply finite net `realized_pnl`; incomplete or malformed records fail safely. Missing optional labels go into an explicit `unknown` bucket rather than disappearing from totals. Confidence values use fixed non-overlapping buckets and invalid confidence metadata is rejected. Reports and their dimension mappings are immutable and deterministically ordered, making experiment comparisons reproducible. This provides the evidence needed to learn which agents, prompts, sources, companies, and holding periods actually add value after execution costs.
