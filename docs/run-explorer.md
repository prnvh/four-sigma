# Run explorer API

`RunExplorer` provides read-only, structured answers for operational questions about a completed backtest. `why_trade()` joins the selected trade candidate to its thesis references, complete audited lifecycle, matching opening fills, and relevant context snapshot identifiers. `context()` returns the exact immutable view stored for a context snapshot rather than rebuilding it from newer data. `insight_origin()` resolves an insight version to the governance proposal that created it through shared-memory version history. `why_resized()` compares the original audited requested size with the risk-reviewed size and returns the recorded reason, whether or not a resize occurred. Trade registration now records direction, original size, and thesis references in the append-only audit ledger so later explanations do not infer missing facts. Queries reject unknown run records and explicitly report when the optional context or shared-memory source was not supplied. The API returns dataclasses instead of prose, making it suitable for a later UI or HTTP layer without downstream text interpretation. It never modifies the run, reconstructs unavailable context, or generates an explanation with an AI model.
