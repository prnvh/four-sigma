# Risk Loss-Control Repair

The repaired risk path fails closed when the advisory model errors, emits malformed output, cites unsupported evidence, or receives no sourced context. Such failures now produce a rejected/deferred candidate at zero size instead of the previous full-size `ALLOW` decision. A separate deterministic loss guard runs before advisory portfolio and trade-risk models, so no AI response can override it. The guard blocks averaging down into a losing position, enforces configurable position stop-loss and portfolio drawdown thresholds, and marks hard-loss conditions for exit. After a realized losing close, the same symbol cannot be re-entered until a configurable cooldown has elapsed; profitable closes reset the consecutive-loss streak. The backtest records net closing outcomes in this guard and updates peak equity continuously rather than only during portfolio-agent calls. Default limits are a 10% portfolio drawdown, 8% position loss, one consecutive loss, and a five-day cooldown, all configurable through strategy settings. Deterministic drawdown vetoes now activate at the configured boundary rather than only after exceeding it. These controls cannot guarantee profitable trades, but they prevent model errors and stale bullish theses from automatically escalating repeated losses.
