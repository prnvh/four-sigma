# Agent-Level Evaluation (Commit 38)

The agent evaluator turns immutable run, governance, token, and realized-outcome records into comparable metrics for every agent version and model. It reports total, successful, and failed runs alongside accepted and rejected promotion proposals. Directional accuracy compares each recorded prediction with its realized direction, while a Brier score measures whether confidence was calibrated to correctness rather than merely sounding certain. Average latency and separate input, output, and total token counts come directly from the AgentRunner audit trail. Estimated cost uses caller-supplied per-million-token model prices so rapidly changing vendor pricing is never hard-coded into research logic. Runs with billable tokens but no matching price deliberately report unknown cost instead of a misleading zero. Missing realized outcomes remain unscored and do not distort accuracy or calibration, while duplicated or unknown outcome records fail validation. Grouping by agent ID, agent version, and model makes prompt/model experiments and later ablation studies directly comparable. This provides evidence for deciding which agents improve the system enough to justify their latency, inference cost, and governance burden.
